# Argumentation & Critical Thinking for Biblical Studies

This package is structured for Sword Drill Academy and optimized for a web app deployment such as React on Vercel.

## Contents
- `course.json` - root metadata and grading model
- `modules/` - eight major modules in JSON form
- `activities/` - oral prompts, rapid-fire drills, and scenarios
- `assessments/competency_checkpoints.json` - non-writing gate system before final
- `assessments/final_exam_125.json` - final exam bank

## Design Intent
This course is built to train learners in argument structure, formal and informal logic, fair representation of competing views, and responsible use of scripture in live debate settings.

## Best Uses in App
- progress bars per module
- badge and XP unlocks
- timed drills
- audio listening / voice response modes later
- simulation arena with branching responses

## Non-Writing Competency Demonstration Ideas
1. Tap-to-sort claim, premise, conclusion
2. Timed fallacy identification
3. Drag-to-reconstruct syllogisms
4. Audio: hear a claim and identify the hidden assumption
5. Branching debate tree
6. Oral 30-second answers scored by rubric

## Suggested Optional UI Labels
- Apprentice Analyst
- Junior Logician
- Context Guard
- Cross-Examiner
- Sword Drill Logician

## Notes
The content is intentionally broad enough to work across Christian debate topics while still remaining useful in biblical studies contexts. It is designed as a capstone-quality course, not an introductory survey.
