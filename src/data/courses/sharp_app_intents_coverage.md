# Sword Drill App Intent Coverage

## How To Use Study Plans
To use Sword Drill study plans:
1. Open the app and go to study plans.
2. Pick a book or topic plan.
3. Follow the daily reading sections and memory verses.
4. Track completion as you finish each section.

Key terms: study plan, study plans, reading plan, memory verses, progress tracking.

## How To Start A Course
To start a Sword Drill course:
1. Open courses.
2. Select a course module.
3. Read lesson content and complete quizzes.
4. Continue through levels in order.

Key terms: course, module, lesson, quiz, level progression.

## How To Use SHARP Assistant
SHARP answers Bible and Sword Drill questions using local indexed knowledge.
Best results come from specific prompts such as:
- a verse reference (example: Romans 8:28)
- a doctrine term (example: sanctification)
- a feature question (example: how study plans work)

## Bible Tools In Sword Drill
Sword Drill includes Bible study tools such as:
- translations (KJV, ASV, WEB, YLT where available)
- Strong's and lexicon style study support
- topical and course-based learning content

## Troubleshooting App Questions
If SHARP says confidence is low:
1. Ask a narrower question.
2. Include a reference, topic keyword, or exact feature name.
3. Retry with translation preference when needed.
