# Module 1 – What Is Religion?

Religion in Scripture is not merely belief but allegiance, worship, and obedience.
Biblical religion is covenantal, exclusive, and revelatory.

Key Texts:
- Deuteronomy 6:4–5
- Exodus 20:1–3
- James 1:27

Scripture frames religion around:
1. Object of worship
2. Law or instruction
3. Means of restoration
4. Final end

Any system answering these apart from YHWH constitutes another religion.
