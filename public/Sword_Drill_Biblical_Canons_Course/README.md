# Sword Drill Course: Biblical Canons

This is a fully self-contained, exhaustive course designed for use with the **Sword Drill** Bible study and memory app.

## Course Goals
- Understand what a biblical canon is
- Learn every major canon tradition in history
- Compare books, order, theology, and authority claims
- Equip learners to quickly identify canon differences in Sword Drill format

## Recommended Mode
- Sword Drill Timed Recall
- Canon Comparison Quizzes
- Verse Authority Challenges

All content is public-domain or original educational material.
